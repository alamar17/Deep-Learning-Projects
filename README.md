# Deep-Learning-Projects

Deep Learning & Neural Networks Portfolio

The Wine Quality Classification project serves as a comprehensive demonstration of applying a Multi-Layer Perceptron (MLP) to multivariate chemical data. Utilizing a dataset of 178 samples, the objective is to categorize wines into three distinct classes based on 13 chemical features, including attributes such as alcohol content, malic acid, and color intensity. By architecting a custom neural network in the PyTorch framework, the model successfully captures the subtle chemical "fingerprints" of each wine category, ultimately achieving a verifiable test accuracy of 91.67%.

The educational foundation of this project rests on the principles of reproducibility and non-linear pattern recognition. In professional data science, results must be repeatable; therefore, this implementation utilizes a fixed manual seed of 42 to synchronize the pseudo-random number generators across Python, NumPy, and PyTorch. This ensures that the initial weight distribution and the shuffling of data remain identical across every execution. Furthermore, the model employs the Rectified Linear Unit (ReLU) activation function. ReLU is critical because it introduces non-linearity, mimicking the firing threshold of a biological neuron. By only passing signals that exceed a value of zero, ReLU allows the network to learn complex relationships in the chemical data that would be impossible for a standard linear model to identify.

From a technical perspective, the pipeline includes rigorous data preprocessing using Scikit-Learn. Features are transformed using a standard scaler to ensure all chemical measurements exist on the same scale, which prevents features with larger numerical ranges from disproportionately influencing the gradient updates. The architecture consists of an input layer of 13 neurons, two hidden layers of 10 neurons each, and a final output layer of 3 neurons corresponding to the wine classes. The training process utilizes the Adam optimizer and Cross Entropy Loss over 100 epochs. This project sits alongside other advanced implementations in my portfolio, including Project 3 (Image Classification) and Project 10 (Generative Adversarial Networks), to showcase a broad command of deep learning architectures and data integrity standards.
